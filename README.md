# 情绪日记 - Mood Diary

这是一个情绪日记小程序项目。

## 文件说明

本项目包含以下文件：

- `app-service.js.map` - 主服务映射文件
- `appservice.app.js.map` - 应用服务映射文件
- `chunk_*.appservice.js.map` - 代码块映射文件

## 用途

这些.map文件是源代码映射文件，用于调试和开发过程中将压缩/编译后的代码映射回原始源代码。

## 技术栈

- JavaScript/TypeScript
- 小程序开发框架

## 如何开始

1. 克隆此仓库
2. 使用相应的小程序开发工具打开项目
3. 根据需要进行开发和调试
